# Voldigoade Portfolio

Personal developer portfolio for Voldigoade, featuring public projects, technical writing, and a bilingual French and English interface.

Canonical site: [voldigoade.xyz](https://voldigoade.xyz)

## Stack

- Next.js
- React
- TypeScript
- Bun
- Pages CMS
- Vercel
- Cloudflare Web Analytics

## Featured Projects

- [Spoor](https://github.com/Voldigoade/spoor): Rust CLI and HTTP service for inspecting public GitHub footprints.
- [Crucksware](https://github.com/Voldigoade/crucksware): Rust prototype for diffing extracted Linux firmware rootfs trees.
- [Recherche Messageries](https://github.com/Voldigoade/recherche-messageries): Source-backed evaluation of encrypted messaging protocols.
