# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.x.x+  | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or credential exposure risk in this repository, please report it privately:

1. Open a confidential report via GitHub Security Advisories at [https://github.com/Voldigoade/portfolio/security/advisories/new](https://github.com/Voldigoade/portfolio/security/advisories/new).
2. Alternatively, reach out via the [contact form](https://voldigoade.xyz/contact) with the subject "Security Vulnerability".

Please include:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept.
- Potential impact and affected endpoints or components.

We take security issues seriously and will respond promptly to review and remediate any confirmed vulnerabilities before public disclosure.
