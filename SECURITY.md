# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.x.x+  | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it confidentially using GitHub Security Advisories:

1. Open a confidential report at [https://github.com/Voldigoade/portfolio/security/advisories/new](https://github.com/Voldigoade/portfolio/security/advisories/new).

Please include:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept.
- Potential impact and affected endpoints or components.

Do not disclose security vulnerabilities through public GitHub issues or discussions. Confirmed vulnerabilities will be reviewed and remediated promptly before coordinated disclosure.
